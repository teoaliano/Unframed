# Starter content for a new project

A new project opens with two prompts, one referencing the other by `@id`, so the first thing a person sees shows how references compose. Both ids come from the same id counter as shapes a person adds; nothing carries a hand-written id.

- Subject prompt, text: `lone red fox`
- Scene prompt, above it, text: `A @<subject id> on a windswept cliff at golden hour, cinematic, 35mm`

The old app also placed an image output node wired from the scene prompt. The new canvas has no output nodes: selecting the scene prompt and pressing Generate is the equivalent.
