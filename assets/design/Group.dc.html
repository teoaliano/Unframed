Selecting a group selects its contents. One click on the box gives the same bar, and the members expand in place in the same top‑to‑bottom order — the rule bucketSources already uses for a wired group.
So the group adds nothing new: it is a named, reusable selection. The hint reads @character instead of a count, because the set has a name.
Agent on a group is the same thing it is today: everything inside goes with the message.
