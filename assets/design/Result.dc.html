The result is an ordinary image node — the same one an upload makes. It can be selected into the next generation with no conversion step, which is the whole point of dropping the output node.
It carries its own recipe (the sidecar already on disk): sources, model, parameters, the run’s instruction. That is what makes Regenerate and Vary possible with no wires and no second object.
Recipe reopens the Generate sheet filled in, so “same thing, bigger” is two clicks. The open question is how far that memory should reach — see the next page.
The dashed tether is provenance, not a wire: it is drawn only while the result is selected, it carries nothing, and deleting a source does not break the node.
